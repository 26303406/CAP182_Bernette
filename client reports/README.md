# Client Reports

This folder contains the client-facing and assignment-related reports for the CAP182 project. It stores documents prepared for business communication, recommendation delivery, and project reporting.

## Purpose

The materials in this folder are used to translate the technical analysis into clear business outputs for STADIOEquities. They support decision-making around customer activation, onboarding risk, and retention improvement strategies.

## Included documents

- 26303406_Bernette_CAP182_SS1_PartC Data Request.pdf
  Data request document outlining the project dataset and required customer, onboarding, and engagement variables.

- 26303406_Bernette_CAP182_SS2_Part D Recommendation (28-sep-26).pdf
  Final client-facing recommendation report summarising the project findings, model results, and business recommendations.

## Role in the project

This folder complements the technical workflow in the preprocessing, feature engineering, modelling, and evaluation stages. The outputs here are designed for stakeholder communication and decision support rather than model development alone.

## Typical use

- review the project scope and data requirements
- understand the business problem and solution framing
- present findings to stakeholders in a client-ready format
- communicate recommended actions for activation and retention strategy
